🐲 KRAKER MASTER

Guía de instalación — el orden SÍ importa · versión 3.0
Lee esto primero. El panel tiene 18 módulos, pero solo 5 son obligatorios y tienen un orden. Si te saltas uno, los puertos parecen abiertos pero nadie puede conectarse. Sigue los pasos tal cual.

Antes de empezar

  • VPS con Debian 11/12/13 o Ubuntu 20.04 / 22.04 / 24.04
  • Acceso root (o sudo)
  • Mínimo 512 MB de RAM (1 GB recomendado)
  • Tener a mano el panel del proveedor (AWS, Hetzner, OVH, Vultr, Contabo) para abrir los puertos allá también
⚠️ El error #1 de todos: abrir los puertos solo dentro del VPS y olvidar el firewall del proveedor. Son dos firewalls distintos. Si los puertos escuchan en el VPS pero desde fuera no conecta, el bloqueo está en el panel del hosting.

Instalación (1 comando)

bash <(curl -fsSL https://raw.githubusercontent.com/lorunder/Script-kraker-/main/install.sh)

Al terminar, escribe kraker para abrir el panel.

Los 5 pasos obligatorios, en orden

1 Dropbear obligatorio

Menú [10] — Dropbear Manager

Por qué primero: es el destino del túnel. Todo lo demás le apunta a él. Si no está arriba, el 443 abre y cierra la conexión al instante.

Debe quedar escuchando en 80, 143 y 442.

2 Abrir puertos obligatorio

Menú [17] — Abrir Puertos

Por qué: abre 22, 80, 143, 442, 443 y 7100-7300 en el firewall del VPS. El puerto 22 se abre siempre primero, para que no te quedes fuera.

Aprovecha y abre en el panel del proveedor: 22, 80, 143, 442, 443, 7100-7300 (TCP) y 443, 53, 5300 (UDP).

3 SSL Gateway en modo PYTHON obligatorio

Menú [03] → elige la opción [2] PYTHON

Nota: [03] y [04] abren el mismo menú, así que da igual cuál uses. Lo que importa es elegir 2 = PYTHON adentro.

Por qué Python y no Stunnel: tus clientes entran de dos formas distintas y ambas usan el mismo puerto 443. El gateway de Python detecta solo:

Lo que manda el clienteQué hace el gateway
GET / HTTP/1.1... (payload WebSocket)Responde 101 y quita las cabeceras
SSH-2.0-... (SSL puro)Pasa directo sin tocar nada
No manda nada (espera al servidor)Pasa directo también

Stunnel solo sirve si TODOS tus clientes usan SSL puro. Si tienes mezcla, usa Python o los de payload no conectarán.

4 UDP Gaming (BadVPN) obligatorio si hay Free Fire

Menú [08] — UDP Gaming

Por qué: convierte el UDP del juego en TCP para que pueda viajar por el túnel. Sin esto, Free Fire no pasa.

Debe quedar escuchando en 7100, 7200 y 7300.

Ojo: esos puertos son TCP, aunque el módulo se llame "UDP Gaming". El cliente se conecta por TCP.

5 Tuner Gaming recomendado

Menú [18] — Tuner Gaming

Por qué: activa BBR + fq_codel y agranda los buffers UDP. Eso es lo que hace que el ping sea estable en vez de dar picos.

Te muestra el ping y el jitter antes y después. Si algo va mal, se deshace con bash scripts/KRAKER_Gaming.sh --revert.

6 Crear usuarios cuando ya funcione

Menú [12] — Gestión de Usuarios

Primero comprueba que el túnel funciona tú mismo, y después creas cuentas. Cada usuario recibe un comprobante con los puertos y datos de conexión.

Verificación: lo único que importa

No te fíes del panel. Ejecuta esto y comprueba que salgan todos los puertos:

ss -ntl | grep -E ':(22|80|143|442|443|7100|7200|7300) '

Salida esperada (8 líneas con LISTEN):

LISTEN 0 4096 0.0.0.0:22    <- tu acceso SSH, NUNCA lo cierres
LISTEN 0 1024 0.0.0.0:80    <- Dropbear
LISTEN 0 1024 0.0.0.0:143   <- Dropbear
LISTEN 0 1024 0.0.0.0:442   <- Dropbear
LISTEN 0 2048 0.0.0.0:443   <- SSL Gateway
LISTEN 0 2048 0.0.0.0:7100  <- BadVPN
LISTEN 0 2048 0.0.0.0:7200  <- BadVPN
LISTEN 0 2048 0.0.0.0:7300  <- BadVPN
Si los 8 aparecen, la cadena está completa. Si falta el 443, repite el paso 3. Si faltan 7100-7300, repite el paso 4.

Lo que NO debes hacer

  • No actives UFW sin haber abierto el 22 antes. Te quedas sin acceso al VPS.
  • No uses [20] Desinstalar si tienes clientes activos: borra el panel y los scripts.
  • No uses [06] Anti-Torrent: sus reglas no filtran el tráfico del túnel y pueden romper la navegación.
  • No reinicies Dropbear desde el VPS con gente conectada: se les corta la sesión.
  • No pidas a los clientes que usen Fortnite o LoL: un túnel TCP no transporta el UDP de esos juegos (ver anexo).
